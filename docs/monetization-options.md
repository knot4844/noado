# 수익화 검토 — "온라인에 팔 수 있는 것"

작성일: 2026-08-19
질문: *"내가 나만 알고 있는, 온라인에 팔 수 있는 방법이 뭘까? 100만원을 벌 방법은?"*

이 문서는 **검토 결과이지 실행 승인이 아니다.** 형이 고르면 그때 만든다.

---

## 0. 먼저 정직하게

| 사실 | |
|---|---|
| 세션(블씨)은 돈을 벌어오지 못한다 | 계정 개설·정산·구매자 응대는 사람이 해야 한다 |
| 만들 수 있는 것은 **팔 물건**까지다 | 원고·서식·판매 문구·썸네일 |
| 애드센스는 **단기 100만원 경로가 아니다** | 아직 승인도 안 났고, 승인 후에도 월 100만원은 월 수십만 PV 규모다 |
| 가장 빠른 경로도 **원고 2주 + 판매 1~3개월** | 이번 달 생활비가 급한 상황이라면 이 문서의 어떤 방법도 늦다 |

## 1. 형만 아는 것 — 저장소에서 실제로 확인된 것

`docs/caregiver-facts.md` 에 운영자 본인 확인으로 기록된 것 중,
**공식 자료에도 없고 기존 블로그에도 없는 것**만 추렸다.

### ① 인정조사의 각성 현상 (가장 값진 하나)

> "공단에서 사람 나와서 치매 등급 판정하러 나오면 그때 정정해져.
> 그리고 그 사람 가면 온 집안에 오줌싸고 똥싸고 그런다"

- 조사원 앞에서 어르신이 일시적으로 또렷해진다 → 배설 항목이 통째로 누락된다
- 배설은 ADL 배점이 큰 항목이다 → **등급이 실제 부담보다 낮게 나온다**
- 인정조사는 하루 한 번 방문으로 끝나므로 **구조적으로 반복되는 문제**다
- 그런데 이걸 적어둔 자료가 공단에도 블로그에도 거의 없다

**팔 수 있는 형태로 바뀌는 지점:** 대응책이 "기록"이라는 것. 말로 하면 안 반영되고
날짜별 메모·사진이 있어야 한다. → **기록지라는 물건이 나온다.**

### ② 호스피스 60일은 이론, 실제는 한 달

- 수가 기준 60일을 믿고 들어갔다가 **한 달 무렵 "다른 곳을 알아보라"** 는 안내를 받는다
- 이유는 규정이 아니라 병상 대기 수요. 곳에 따라 2주인 데도 있다
- 그래서 보호자에게 진짜 필요한 조언은 "60일 전에 준비하세요"가 아니라
  **"들어가는 날부터 다음 곳을 알아보세요"** 다

### ③ 검색어와 실제 문제의 간극

- 사람들은 "부모님 요양원 **설득** 방법"을 검색한다
- 겪은 사람의 답은 **"그냥 내가 모시고 갔다"** 였다
- 실제 문제는 설득이 아니라 **옮기는 일**이었다 — 차 → 주차 → 휠체어 가져오기 →
  옮겨 태우기 → 진료 → 다시. 집에서는 안고 올라가야 했다
- 시중 글 전부가 화술을 답하고 있다. **이 간극 자체가 상품성이다**

### ④ 5단계를 한 사람이 전부 겪었다

```
가족 직접 돌봄 → 방문요양 → 주간보호 → 요양원 → 상급병원 호스피스 → 별세 → 사후 행정
```

각 단계 경험자는 많다. **전 단계를 순서대로 겪고 그걸 문서로 남긴 사람은 드물다.**
그리고 이 경로는 "언제 무엇을 해야 하는가"라는, 공식 자료가 절대 못 주는 정보다.

### ⑤ 기한을 놓쳐서 못 받은 지원금이 있다

> "일찍부터 신청해야 받을 수 있었던 걸 모르고 있다가 늦게 신청하고,
> 일찍 돌아가셔서 못 받았다"

**실패담이 성공담보다 팔린다.** 특히 소급이 안 되는 제도에서는.

### 반대로, 팔리지 않는 것

| | 이유 |
|---|---|
| 요양보호사 자격증 (10여 년 전) | 실무 경력이 없다. 자격만으로는 차별점이 아니다 |
| 제도 요약·정리 능력 | 복지로·공단이 무료로 더 정확하게 제공한다. 108편이 거절된 이유가 이것이다 |
| AI 블로그 운영법 | 포화 시장인 데다, 아직 승인도 못 받았다. 팔 자격이 없다 |

## 2. 팔 수 있는 형태 — 4개 후보

### A. 전자책 — 추천 1순위

**가제: "아버지를 보내드리며 놓친 것들 — 재가부터 임종 후 행정까지"**

| | |
|---|---|
| 근거 자료 | 이미 있다. 108편 + `caregiver-facts.md` + `hospice-research.md` |
| 내가 할 일 | 목차·초안·팩트체크·서식 부록·판매 문구·표지 |
| 형이 할 일 | 사실 확인 인터뷰(빈칸 채우기), 계정 등록, 정산 |
| 예상 기간 | 원고 2주 (하루 3편 발행과 병행 시 3주) |
| 가격대 | 12,000 ~ 19,000원 |

**부록이 핵심 구매 이유가 되게 만든다:**
- 인정조사 대비 **14일 기록지** (조사표 65개 점수 항목 기준으로 칸을 설계)
- 사후 행정절차 체크리스트 (사망신고·안심상속·장제급여 순서와 기한)
- 단계 전환 판단표 (언제 방문요양에서 주간보호로 넘어가야 하는가)

### B. 1:1 경험 상담 — 추천 2순위 (A와 병행)

| | |
|---|---|
| 형태 | 30분 통화 또는 채팅, 3만원 |
| 강점 | 객단가가 높다. 10건이면 30만원 |
| 약점 | 형의 시간이 든다. 확장이 안 된다 |
| **반드시 지킬 선** | **제도 상담이 아니라 "겪은 사람의 경험 공유"로 한정한다.** 판단은 관할 기관에서 받으시라고 매번 안내한다 |

전자책 구매자에게 상담을 붙이는 순서가 자연스럽다.

### C. 애드센스 — 장기 자산, 단기 현금 아님

승인 자체는 반드시 받아야 한다. 다만 **월 100만원은 지금 규모에서 몇 년 걸린다.**
"100만원"의 답으로 애드센스를 내미는 건 정직하지 않다.

### D. 제휴(쿠팡파트너스 등) — 지금은 하지 않는다

수수료율이 낮아 100만원을 만들려면 거래액이 수천만원 필요하다.
**게다가 심사 중인 사이트에 제휴 링크를 까는 건 위험하다.** 나중에 본다.

## 3. 100만원 산수 — 뭉개지 않고

> 아래 수수료는 2026-08-19 검색으로 확인한 **2차 자료**다.
> 실제 계약 전에 플랫폼 공식 정책에서 다시 확인해야 한다.

| 경로 | 가격 | 수수료 | 건당 순수익 | **100만원까지 필요 건수** |
|---|---|---|---|---|
| 크몽 전자책 | 15,000원 | 약 20% | 약 12,000원 | **약 84건** |
| 자체 판매(스마트스토어 등) | 15,000원 | 3~6% | 약 14,200원 | **약 71건** |
| 부크크 전자책 | 15,000원 | 인세 50%+ | 약 7,500원 | **약 133건** |
| 1:1 상담 | 30,000원 | 약 20% | 약 24,000원 | **약 42건** |
| 애드센스 | — | — | — | **월 30만~100만 PV** |

**부크크는 자체 마켓에서만 유통된다** (교보·예스24 등 메이저 유통 없음).
인세율이 높아도 사람이 안 오는 곳이면 의미가 없다. 이 표에서 인세율만 보고 고르면 안 된다.

### 현실적인 조합

```
전자책 60건 × 12,000원  =  72만원
상담   12건 × 24,000원  =  29만원
                          ─────────
                          약 101만원
```

**이게 몇 달이 걸릴지는 트래픽에 달려 있다. 그리고 그 숫자를 우리는 아직 모른다.**

## 4. 지금 막고 있는 것 — 트래픽 숫자가 없다

`docs/community-engagement.md` 는 GA4 분석 루프를 전제로 쓰여 있는데,
**HANDOFF 어디에도 실제 방문자 수가 없다.** 서치콘솔은 "발견된 페이지 109"만 적혀 있다.
색인 수는 트래픽이 아니다.

전자책을 만들어도 팔 곳이 없으면 창고에 쌓인다. 그래서 순서는 이렇다.

| 순서 | 할 일 | 누가 |
|---|---|---|
| 1 | 서치콘솔 **실적** 탭 — 최근 28일 노출수·클릭수·상위 질의 확인 | 형 (스크린샷이면 충분) |
| 2 | 그 숫자를 보고 판매 경로를 정한다 | 블씨 |
| 3 | `caregiver-facts.md` 빈칸 인터뷰 (전자책 원고의 뼈대) | 형 + 블씨 |
| 4 | 원고 작성 | 블씨 |

**노출이 하루 수백 미만이면** → 블로그 유입에 기대지 말고 크몽 자체 검색으로 판다.
**노출이 붙고 있으면** → 자체 판매가 수수료 면에서 유리하다.

## 5. 하지 말아야 할 것

1. **심사 결과 전까지 블로그 본문에 판매 링크를 심지 않는다.**
   `CLAUDE.md` 4번(승인 전 광고 off)과 같은 이유다. 심사 중인 사이트가 갑자기
   상업적으로 보이면 잃을 게 더 크다. 팔더라도 **별도 채널에서** 판다.
2. **팩트체크 규칙은 전자책에 그대로, 더 세게 적용된다.**
   돈을 받는 순간 기준이 올라간다. `CLAUDE.md` 5번의 6단계를 그대로 지킨다.
3. **특정 병원·시설 실명은 전자책에도 쓰지 않는다.** (`CLAUDE.md` 6번)
4. **발행 상한(하루 3편)을 수익화를 이유로 올리지 않는다.**
   거절 원인이 그거였다. 전자책 원고 때문에 발행이 밀리면 밀리는 게 맞다.
5. **"이렇게 하면 월 100만원" 식의 문구를 쓰지 않는다.**
   가족요양보호사 글에서 우리가 비판한 바로 그 화법이다. 우리가 하면 안 된다.

## 6. 결론 한 줄

**형이 가진 것은 정보가 아니라 순서와 시점이다.**
제도 설명은 공단이 더 잘한다. 하지만 *"조사원이 오는 날 아버지가 멀쩡해지신다"*,
*"호스피스는 들어가는 날부터 다음 곳을 알아봐야 한다"* 는 겪은 사람만 안다.

그걸 **기록지와 체크리스트라는 물건**으로 바꾸는 것이 팔 수 있는 형태다.
