## 돌봄 경로 (2026-08-16 확인)

아버지를 돌본 형태가 시기에 따라 다섯 번 바뀌었다. **한 사람이 전 단계를 겪은 기록**이라
이 사이트에서만 쓸 수 있는 내용이다.

```
가족이 직접 돌봄
   ↓
방문요양
   ↓
주간보호센터
   ↓
요양원 입소  ── 한 달도 안 되어 상태 악화
   ↓
상급병원 호스피스 (약 1개월)
   ↓
1개월 무렵 "다른 곳을 알아보라" 안내 → 찾는 중 병세 악화, 하루이틀 뒤 별세
```

### 이 경로가 닿는 글

| 단계 | 관련 글 |
|---|---|
| 재가 돌봄 | 노인-맞춤돌봄서비스 / 노인돌봄서비스 / 재가노인복지시설 |
| 방문요양 | 방문요양-서비스-본인부담금 |
| 주간보호 | 주간보호센터-비용-계산-방법 |
| 요양원 | 요양원-요양병원-비용-차이 |
| 호스피스 | **해당 글 없음 → 신규 작성 후보** |

### 특히 값진 지점

**호스피스에서 "다른 데 가라"는 안내를 받고 옮길 곳을 찾던 상황.**
국내 호스피스 병동의 재원 기간 제한 때문에 많은 가족이 같은 일을 겪지만,
공식 자료에도 기존 블로그에도 거의 정리되어 있지 않다. 검색 수요는 있는데
답이 없는 자리다. 다만 **가장 아픈 대목이므로 서술은 조심스럽게 한다.**

**2026-08-16: 운영자가 글로 다뤄도 좋다고 확인함.** 사실 중심으로,
재원 기간 제한이 왜 생기는지와 미리 준비할 것 위주로 쓴다.

### 가족요양보호사 (2026-08-16 확인)

| 항목 | 운영자 확인 사실 |
|---|---|
| 제도를 알았는가 | **알고 있었다** |
| 등록했는가 | **안 했다** |
| 안 한 이유 | **"우리가 그 정도의 능력이 되지 않아서."** 직접 돌보는 것 자체가 감당이 안 됐다 |
| 실제 돌봄 구조 | 요양보호사가 와서 돌보고, **가족은 옆에서 거드는 수준** |
| 요양보호사 퇴근 후 | **어머니나 본인이 돌봤다** — 급여 시간 외는 온전히 가족 몫 |

**이것이 ①번 글의 핵심 각도다.** 시중 글은 전부 "가족요양으로 월 100만원"
으로 유혹하는데, 실제로는 **자격이 있어도 직접 돌볼 능력이 안 되면 의미가 없다.**
그리고 급여로 인정되는 건 하루 60~90분뿐이고 나머지 시간은 어차피 무급이다.
운영자의 경험이 그걸 그대로 보여준다.

### 인정조사의 함정 (2026-08-16 확인) — **별도 글감**

| 항목 | 운영자 확인 사실 |
|---|---|
| 등급 받기 | **쉽지 않았다** |
| 이유 | 아버지 상태가 **날마다 달랐다.** 괜찮을 때도 있고 아닐 때도 있었다 |
| 결정적 관찰 | **"공단에서 사람 나오면 괜찮아지고, 그 사람 가면 상태가 안 좋아진다"** |

**2026-08-16 추가 확인 — 구체적으로 무엇이 누락되는가**

| 조사 당일 | 조사원이 돌아간 뒤 |
|---|---|
| 아버지가 **정신이 또렷해지셨다** | **집 안 곳곳에 실금·실변** |

운영자 표현: "공단에서 사람 나와서 치매 등급 판정하러 나오면 그때 정정해져.
그리고 그 사람 가면 온 집안에 오줌싸고 똥싸고 그런다"

**이것이 왜 결정적인가 — 배설 관련 항목은 인정점수 배점이 크다.**
일상생활수행능력(ADL) 평가에 대소변 조절이 포함되는데, 조사 당일에만
증상이 안 나타나면 **가장 무거운 항목이 통째로 누락된다.** 등급이 실제
돌봄 부담보다 낮게 나오는 전형적인 경로다.

대응은 **기록**이다. 간병 일지·사진·날짜별 메모를 조사원에게 보여주는 것.
"평소에는 이렇습니다"를 말로만 하면 반영되기 어렵다.

**서술 원칙 (2026-08-16 운영자 지적으로 정정)**

처음에 "증상을 구경거리로 쓰지 않는다"고 적었으나 **이 표현이 잘못됐다.**
운영자의 지적: *"아버지 돌아가셨는데 뭔 구경거리야. 다른 사람들에게
실제 경험했던 것에 대한 이만한 고증이 어디 있어?"*

맞는 말이다. 증상을 숨기는 것은 존중이 아니라 오히려 그것을 부끄러운 일로
취급하는 것이다. **있는 그대로 적는 것이 고증이고, 그게 같은 일을 겪는
가족에게 실제로 도움이 된다.** 다른 어떤 자료도 이걸 적어주지 않는다.

지킬 것은 하나뿐이다 — **연민을 구걸하거나 자극적으로 소비하지 않는다.**
사실을 담담하게 적고, 그것이 제도의 어느 지점을 드러내는지 연결한다.

### 단계 전환과 이동 (2026-08-18 확인) — **허브 글의 핵심**

**"어떻게 설득했나" 를 물었더니 설득 이야기가 아니라 이동 이야기가 나왔다.**

| 항목 | 운영자 확인 사실 |
|---|---|
| 설득 과정 | **없었다.** "그냥 내가 모시고 갔다" |
| 병원 한 번 가는 실제 절차 | 차 가져오기 → 주차 → 병원 올라가 **휠체어 가져오기** → 아버지를 차에서 휠체어로 옮기기 → 진료 → 다시 차로 옮기기 |
| 집에서 | **"그냥 안고 올라가야 했다"** |

**이것이 이 글의 각도다.** 검색창에는 "부모님 요양원 설득 방법" 이라고 치지만,
**실제로 닥치는 문제는 설득이 아니라 옮기는 일이었다.** 말로 되는 상황이
아니고, 몸으로 되는 일이었다.

시중 글은 전부 "이렇게 대화하세요" 로 답한다. 그런데 정작 겪은 사람의 답은
"그냥 내가 모시고 갔다" 다. **이 간극이 이 글의 존재 이유다.**

→ 그래서 글의 무게는 **설득 화술이 아니라 이동을 덜어주는 제도**에 실어야 한다.
   (병원 동행 서비스, 복지용구 휠체어·이동보조, 주택 내 이동, 계단 문제 등)

**서술 주의:** "안고 올라갔다"는 담담하게 한 번만 적는다. 힘들었다는 것을
강조하지 않아도 문장 자체가 이미 그것을 말한다.

## 쓸 때 지킬 것

- **단정적 조언 금지.** "~하세요" 대신 "저희는 ~했습니다", "~라고 안내받았습니다".
- **특정 병원·시설·담당자 실명 금지.**
- **2023년 기준임을 밝힌다.** 제도가 바뀌었을 수 있으므로 현재 기준과 다를 수 있다고 적는다.
- **숫자는 기억이 확실한 것만.** 애매하면 "정확히는 기억나지 않지만" 을 붙이거나 빼버린다.
- **증상을 감추지 않는다.** 실금·실변처럼 드러내기 어려운 것도 사실대로 적는다.
  숨기면 고증이 안 되고, 같은 일을 겪는 가족에게 도움이 되지 않는다.
  다만 **자극적으로 소비하거나 연민을 구걸하지 않는다.** 담담하게 적고
  그것이 제도의 어느 지점을 드러내는지로 연결한다. (2026-08-16 운영자 지적)
- 보호자 노트는 **공식 정보의 대체가 아니라 보완**이다. 본문의 수치를 뒤집지 않는다.
