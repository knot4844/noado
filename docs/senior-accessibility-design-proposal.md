# 40~70대 스마트 가독성 및 모바일-PC 반응형 디자인 기획서

> **"눈의 피로를 최소화하고 기기 경계 없이 편안하게 읽히는 블로그 시스템"**  
> — 웜 미니멀리즘(Warm Minimalism) 기반 UI/UX 전략

---

## 1. 디자인 컨셉: 웜 미니멀리즘 (Warm Minimalism)

반투명하고 흐릿한 글래스모피즘(Glassmorphism)은 노안이나 시력 저하가 있는 40~70대 사용자에게 글자와 배경의 경계를 모호하게 만들어 오히려 가독성을 저해할 수 있으며, 구형 스마트폰에서 버벅거림을 유발합니다.

따라서 이를 대체할 **"웜 미니멀리즘(Warm Minimalism)"**을 제안합니다.

```
[웜 미니멀리즘 핵심 요소]
1. 소프트 페이퍼 대비: 눈부신 백색(#FFFFFF) 대신 눈이 편안한 미색 종이 질감(#FDFCF9 또는 #F5F2EB) 배경 채택.
2. 진한 차콜 텍스트: 완전 검은색(#000000)은 백라이트 눈부심을 유발하므로, 매우 높은 고대비를 제공하는 진한 차콜색(#2B2B2B)을 글씨색으로 사용.
3. 명확한 윤곽선(Border): 입체적인 효과나 흐릿한 그림자 대신, 1.5px~2px의 얇고 명확한 윤곽선(#E0DCD5)으로 카드와 버튼의 영역을 뚜렷하게 인지시킴.
```

## 2. 40~70대 대상 가독성 서체 설계 (Typography)

중장년층 및 고령층 사용자는 글씨 크기뿐 아니라 **줄간격(행간)**과 **글자 뭉침(자간)**에 매우 민감합니다.

| 구분 | PC (데스크톱) | 모바일 (스마트폰) | 설명 |
|---|---|---|---|
| **본문 기본 크기** | **20px** (`1.25rem`) | **18px** (`1.125rem`) | 일반 웹사이트(14~16px)보다 20% 이상 확대된 크기 |
| **행간 (Line-height)** | **1.9** | **1.8** | 위아래 줄글이 서로 엉켜 보이지 않도록 넉넉한 높이 확보 |
| **자간 (Letter-spacing)**| **-0.02em** | **-0.03em** | 자간을 미세하게 좁혀 단어 단위 인지 속도 향상 |
| **H2 타이틀 크기** | **28px** | **24px** | 문단 구분을 명확히 하는 굵은(Bold) 폰트 표기 |

## 3. 기기별(모바일/PC) 화면 깨짐 방지 대책 (Responsive Layout)

모바일 화면과 컴퓨터 화면 모두에서 레이아웃이 깨지지 않고 완벽히 비례를 유지하도록 만드는 4가지 상시 정합 규칙입니다.

### ① 유동형 그리드 및 패딩 (Fluid Grid & Padding)
- 화면 크기에 따라 패딩과 여백이 자동으로 늘어나거나 줄어들도록 상대 단위(`rem` 및 `vw` 조합)를 사용합니다.
- 좌우 외부 여백을 모바일에서는 `16px(1rem)`, 태블릿/PC에서는 `32px(2rem)`로 유동 설정하여 글자가 화면 좌우 구석에 붙는 현상을 차단합니다.

### ② 표(Table)의 반응형 스크롤 및 카드형 전환
- 가로로 긴 표는 스마트폰 화면에서 깨지거나 잘리는 대표적 원인입니다.
- **해결책 1**: 표를 감싸는 영역에 `overflow-x: auto;` 속성을 부여하여 모바일에서 손가락 스와이프로 안전하게 가로로 밀어서 볼 수 있게 만듭니다.
- **해결책 2 (고도화)**: 화면 너비가 640px 이하로 떨어지면 기존 표 구조를 모바일에 맞는 위아래 줄글 형태의 '카드 목록'으로 자동 변환해 렌더링하도록 CSS 미디어 쿼리를 설계합니다.

### ③ 터치 편의성 및 버튼 최소 여백
- 40~70대 사용자는 손가락 끝 감각이나 제어 정밀도가 떨어져 버튼 오클릭(잘못 누름)이 자주 발생합니다.
- **규칙**:
  - 모든 클릭/터치 대상 버튼은 최소 높이 **52px** 이상을 확보합니다.
  - 버튼과 버튼 사이 간격은 최소 **16px(1rem)** 이상 떨어트려 오클릭을 차단합니다.

## 4. 실전 코드 적용 설계안

글로벌 스타일시트(`src/styles/global.css`)에 즉시 반영할 CSS 설계는 다음과 같습니다.

```css
/* 1. 모바일 우선 및 반응형 타이포그래피 */
html {
  font-size: 16px; /* 기본 16px */
  background-color: #FDFCF9; /* 눈이 편안한 연미색 */
  color: #2B2B2B; /* 눈부심 없는 진한 차콜 */
  font-family: 'Pretendard', system-ui, sans-serif;
  line-height: 1.8;
  letter-spacing: -0.02em;
}

/* 본문 가독성 증폭 */
p, li, td {
  font-size: 1.125rem; /* 18px */
}

/* 태블릿 및 PC 화면에서의 본문 크기 상향 */
@media (min-width: 768px) {
  html {
    font-size: 18px; /* 1.25rem = 22.5px, 기본 본문 = 20px */
  }
  p, li, td {
    font-size: 1.11rem; /* 약 20px */
  }
}

/* 2. 터치 타겟 최적화 */
a, button, input {
  min-height: 52px;
  box-sizing: border-box;
}

/* 3. 모바일 표(Table) 잘림 방지 */
.table-container {
  width: 100%;
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
  margin: 1.5rem 0;
  border: 1px solid #E0DCD5;
  border-radius: 12px;
}

table {
  width: 100%;
  min-width: 500px; /* 스마트폰에서도 가로 스크롤을 유도하기 위한 최소폭 */
}
```
