# 시니어 정책 콘텐츠 라이터 스킬

## 1. 목적

AI 에이전트가 시니어(만 60~65세 이상) 대상 한국 복지·연금·건강·일자리 정책 기사를
일관된 품질로 대량 생산할 수 있도록 하는 **콘텐츠 작성 지시서**.

## 2. 콘텐츠 작성 원칙

### 2.1 문체 규칙
- **경어체** 통일 (~합니다, ~입니다)
- **문장 길이** 25자 이내 권장, 최대 40자
- **한자어/전문용어** 사용 시 반드시 괄호 내 풀이 추가
- 접속사·수식어 최소화; 핵심 정보 먼저 제시
- 숫자·금액은 **볼드** 처리 및 단위 명확 표기

### 2.2 구조 규칙
```
[Frontmatter]
  title: SEO 최적화 제목 (50~60자, 핵심 키워드 2개 포함)
  description: 메타 설명 (120~155자)
  pubDate: ISO 8601
  category: 카테고리 (기초·국민연금 | 건강·의료 | 일자리·취업 | 복지·주거 | 생활·돌봄)
  tags: [관련 태그 5~8개]
  heroImage: /images/posts/{slug}.webp

[본문 구조]
  ## 1. 핵심 요약 (한 눈에 보기)
    → 테이블 or 불릿 3~5개로 핵심 자격/금액/신청처 정리

  ## 2. 자격 조건 상세
    → 연령, 소득, 재산 기준 각각 하위 섹션

  ## 3. 신청 방법 (단계별 가이드)
    → 1단계, 2단계... 넘버링, 온라인/오프라인 분리

  ## 4. 지원 금액·혜택 상세
    → 표(table)로 등급별/유형별 금액 정리

  ## 5. 자주 묻는 질문 (FAQ)
    → 최소 5개, JSON-LD 스키마용 Q&A 구조

  ## 6. 관련 제도 안내
    → 내부 링크 2~3개
```

### 2.3 SEO 규칙
- `<h1>`: title과 동일 (페이지당 1개)
- `<h2>`: 본문 주요 섹션 (5~7개)
- `<h3>`: 세부 항목 (필요 시)
- **키워드 밀도**: 본문 대비 1.5~2.5%
- **내부 링크**: 최소 3개, 관련 기사로 연결
- **이미지 alt**: 키워드 포함 설명문
- **FAQ**: `@type: FAQPage` JSON-LD 스키마 자동 삽입 대상

### 2.4 팩트체크 규칙
- 금액·기준은 **반드시 공식 출처 URL** 기재
- 공식 출처 우선순위:
  1. 보건복지부 (mohw.go.kr)
  2. 국민연금공단 (nps.or.kr)
  3. 정부24 (gov.kr)
  4. 복지로 (bokjiro.go.kr)
  5. 국민건강보험공단 (nhis.or.kr)
- 2026년 기준 미확인 시: "2025년 기준이며, 2026년 변경 사항은 확인 후 업데이트 예정" 명시
- **절대 금지**: 미확인 금액 추정, 법률 해석, 의료 진단 표현

### 2.5 접근성 규칙
- 본문 글자 크기: 최소 18px (CSS에서 처리)
- 색상 대비: WCAG AA 이상
- 링크: 밑줄 + 구별 색상
- 테이블: 모바일 반응형 (수평 스크롤 or 카드형)
- CTA 버튼: 최소 44×44px 터치 영역

## 3. 이미지 생성 규칙

- **스타일**: warm 톤 일러스트, 플랫 디자인
- **색상 팔레트**: #FF8C42 (주황), #4A6FA5 (파랑), #2E8B57 (초록)
- **인물**: 밝은 표정의 시니어 일러스트 (실사 금지)
- **텍스트 오버레이**: 핵심 키워드 1~2개 (큰 글씨)
- **사이즈**: 1200×630px (OG 이미지 호환)
- **포맷**: WebP, 품질 80%

## 4. 품질 체크리스트

발행 전 반드시 확인:

- [ ] 제목에 연도(2026) 포함
- [ ] 메타 설명 120~155자
- [ ] FAQ 최소 5개
- [ ] 내부 링크 최소 3개
- [ ] 금액/기준에 공식 출처 기재
- [ ] 대표 이미지 존재 (heroImage)
- [ ] 카테고리·태그 설정
- [ ] 경어체 통일 확인
- [ ] 모바일 가독성 테스트
