# SEO 옵티마이저 스킬

## 1. 목적

AI 에이전트가 블로그 기사의 SEO 품질을 **자동으로 측정하고 개선 제안을 생성**하는 루프 시스템.
"한번 쓰고 끝"이 아닌, 성과 데이터 기반 **지속적 진화**.

## 2. SEO 체크 항목

### 2.1 온페이지 SEO (필수)

| 항목 | 기준 | 가중치 |
|------|------|--------|
| **Title 태그** | 50~60자, 핵심 키워드 포함, 연도 포함 | 15% |
| **Meta Description** | 120~155자, CTA 포함, 키워드 자연 삽입 | 10% |
| **H1 태그** | 페이지당 1개, title과 일치 | 10% |
| **H2 구조** | 5~7개, 키워드 변형 포함 | 10% |
| **키워드 밀도** | 본문 대비 1.5~2.5% | 10% |
| **내부 링크** | 최소 3개, 관련 기사 연결 | 10% |
| **이미지 alt 텍스트** | 모든 이미지에 키워드 포함 alt | 5% |
| **URL 구조** | 한글 slug, 50자 이내 | 5% |

### 2.2 구조화 데이터 (필수)

| 항목 | 기준 | 가중치 |
|------|------|--------|
| **FAQ Schema** | `@type: FAQPage` JSON-LD, Q&A 5개+ | 10% |
| **Article Schema** | `@type: Article`, author/datePublished 포함 | 5% |
| **Breadcrumb** | 홈 > 카테고리 > 기사 | 5% |

### 2.3 기술적 SEO (필수)

| 항목 | 기준 | 가중치 |
|------|------|--------|
| **페이지 속도** | LCP < 2.5s, FID < 100ms, CLS < 0.1 | 5% |

## 3. 점수 산정

```
SEO Score = Σ(항목별 점수 × 가중치) / 100

등급:
  A (90~100): 출판 가능
  B (75~89):  소폭 수정 후 출판
  C (60~74):  주요 항목 수정 필요
  D (0~59):   재작성 권고
```

## 4. 루프 엔지니어링 프로세스

```
[LOOP START]
  1. 기사 스캔 → SEO 점수 산정
  2. C/D 등급 항목 식별
  3. 자동 수정안 생성 (title, description, heading, FAQ 등)
  4. 수정 적용
  5. 재스캔 → 점수 재산정
  6. A/B 등급 도달 시 → PASS
  7. 미도달 시 → 2번으로 (최대 3회 반복)
[LOOP END → 수동 리뷰 요청]
```

## 5. 자동 수정 규칙

### 5.1 Title 최적화
- 패턴: `{핵심키워드} {보조키워드} {연도}년 최신 가이드`
- 예시: `기초연금 수급자격 재산기준 2026년 최신 가이드`

### 5.2 Meta Description 최적화
- 패턴: `{핵심 혜택/금액} {대상자} {신청방법 요약}. {CTA}`
- 예시: `2026년 기초연금 월 최대 33만원! 만 65세 이상 대상, 온라인 신청 방법부터 자격 조건까지 한눈에 정리했습니다.`

### 5.3 FAQ 자동 추출
- 본문에서 Q&A 패턴 자동 인식
- `<script type="application/ld+json">` FAQ 스키마 자동 생성
- FAQ가 부족 시 관련 검색 질의 기반 추가 생성

### 5.4 내부 링크 추천
- 동일 카테고리 기사 우선
- 키워드 유사도 기반 관련 기사 3~5개 추천
- 앵커 텍스트: 자연스러운 한국어 문구

## 6. 리포트 출력 형식

```markdown
## SEO 분석 리포트: {기사 제목}

| 항목 | 점수 | 상태 | 개선 제안 |
|------|------|------|----------|
| Title | 15/15 | ✅ | - |
| Meta Desc | 7/10 | ⚠️ | 155자 초과 → 3자 축소 필요 |
| ... | ... | ... | ... |

**총점: 82/100 (B등급)**
**자동 수정 가능 항목: 3개**
**수동 검토 필요 항목: 1개**
```

## 7. 성과 추적 (Phase 2)

Google Search Console 연동 후 추가:
- 기사별 노출수/클릭수/CTR/평균 순위 트래킹
- 저성과 기사 자동 식별 (CTR < 2% or 순위 > 20위)
- 개선 루프 자동 트리거
